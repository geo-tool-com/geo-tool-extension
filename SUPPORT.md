# Support

**Bug in the extension?**
[Open a bug report](https://github.com/geo-tool-com/geo-tool-extension/issues/new?template=bug.yml)
— please include browser + version and the kind of page it happened on
(you never need to share the URL itself if it is internal).

**Feature idea?**
[Open a feature request](https://github.com/geo-tool-com/geo-tool-extension/issues/new?template=feature.yml).

**Security issue?**
Never report those publicly — use
[private vulnerability reporting](https://github.com/geo-tool-com/geo-tool-extension/security/advisories/new).

**Question about a score?**
The score is computed by the shared engine documented in the CLI sibling's
[scoring guide](https://github.com/geo-tool-com/geo-tool-check/blob/main/docs/scoring.md)
— extension, CLI, and the website audit always agree by construction.

**Question about geo-tool.com (the hosted product)?**
That support lives at [geo-tool.com/en/contact](https://www.geo-tool.com/en/contact).

The extension sends no telemetry, so we only learn about problems when you
tell us — thanks for taking the minute.
